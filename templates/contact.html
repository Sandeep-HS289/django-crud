Frequently Asked Questions

How does student CRUD operate?

POST is processed natively with standard Django form submissions. PUT, PATCH, and DELETE utilize browser fetch() requests sending JSON bodies with CSRF verification.

Where are the endpoints listed?

All active project endpoints (excluding /admin/) are dynamically discovered and displayed on the Home Dashboard under the Routes Directory.

How is database data stored?

Data is persisted in an SQLite database file (db.sqlite3) managed through Django's model ORM migrations.
